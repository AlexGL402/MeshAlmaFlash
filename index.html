ПрошивкаUF2 / browser workflow
  1. Подключите плату по USB.
  2. Для nRF52840 дважды нажмите RESET, чтобы открыть bootloader.
  3. Откройте диск NICENANO / bootloader в Windows.
  4. Скачайте выбранный .uf2 и скопируйте его на этот диск.
  5. После копирования плата перезагрузится автоматически.
Следующий этап Для ESP32 добавим прямую прошивку из Chrome, erase/update и загрузку собственного firmware — как в крупных web-flasher проектах.
