# ESP-NOW в MeshAlma

ESP-NOW используется как быстрый локальный транспорт для ESP32-C3, ESP32-C6 и ESP32-S3.

## Почему не использовать LoRa для всего

LoRa нужен там, где важна дальность.

Для локальных датчиков ESP-NOW имеет преимущества:

- выше скорость;
- меньше задержка;
- локальная телеметрия не занимает LoRa эфир;
- не нужен отдельный LoRa-модуль;
- дешёвые SENSOR-ноды;
- удобно для нескольких устройств внутри дома или объекта.

## PHY

Поддерживаются:

- BGN
- LR

BGN удобен для обычной Wi-Fi/ESP-NOW совместимости.

LR предназначен для увеличения дальности ESP-NOW, но требует отдельного тестирования совместимости с активным Wi-Fi STA.

## Channel

Все ESP-NOW устройства, которые должны напрямую общаться, должны находиться на одном Wi-Fi channel.

Важно различать:

- Configured channel
- Active channel

Если ESP32 одновременно подключена к Wi-Fi STA, Wi-Fi может определять фактически активный channel.

## Полезные CLI команды

get espnow.status
get espnow.channel
set espnow.channel 1
get espnow.phy
set espnow.phy bgn
set espnow.phy lr
get espnow.txpower

Некоторые изменения применяются только после reboot.

## Где использовать

ESP-NOW хорошо подходит для:

- SENSOR;
- метеостанций;
- энергомониторинга;
- домашней автоматики;
- локальных GPS-трекеров;
- дисплейных companion устройств;
- временных тестовых нод.

Z-Bridge позволяет выпускать выбранные ESP-NOW сущности в MeshCore/LoRa.
